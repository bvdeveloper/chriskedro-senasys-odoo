RELEASE NOTE

Product: Senasys Odoo Customization (chriskedro-senasys-odoo)

Module: bv_senasys_custom_fields

Release Date: February 2025

Version: 15.0

Subject: Drawing Revision Field, Product PDF & Revision Note Attachments on Purchase RFQ/PO Email

1. OVERVIEW

This release introduces enhancements to the Product and Purchase Order modules to support drawing revision tracking and automatic attachment of product drawings and revision notes when sending Request for Quotation (RFQ) or Purchase Order (PO) emails to vendors.

2. FEATURES IMPLEMENTED

2.1 Drawing Revision Field on Product Form

  • A new field Drawing Revision has been added to the Product form.
  • Location: Product → Technical tab → Vendor Drawings/Docs section, placed immediately before the existing PDF 1_1 field.
  • Field type: Text (multi-line).
  • Purpose: Allows users to store revision notes or revision identifiers for product drawings. This value is used to generate the revision note text file attached to RFQ/PO emails.

2.2 Automatic Attachment of Product PDF (pdf_1_1) in RFQ/PO Email

  • When you send an RFQ or a Purchase Order by email ("Send by Email" or "Send PO by Email"), the system now automatically attaches the PDF 1_1 file from each product present on the purchase order lines.
  • If multiple order lines use the same product, the PDF is attached once per product (no duplicates).
  • Only products that have a PDF 1_1 file uploaded will have their PDF attached.
  • The standard PO/RFQ report (e.g. PO_P01789.pdf) continues to be attached as before; product PDFs are added in addition to it.

2.3 Dynamic Revision Note (TXT) File per Product

  • For each distinct product on the purchase order lines, the system generates a text file containing the Drawing Revision value of that product.
  • File naming: revision_note_<Product Part/Name>.txt (e.g. revision_note_ABC-123.txt).
  • Content: The exact text stored in the product's Drawing Revision field. If the field is empty, no revision note file is created for that product (only the PDF is attached if available).
  • These revision note files are attached to the same RFQ/PO email along with the product PDFs and the main PO/RFQ report.

3. TECHNICAL SUMMARY

  • New field: drawing_revision (Text) on product.template and product.product.
  • Product form view updated to display Drawing Revision before PDF 1_1 in the Vendor Drawings/Docs section.
  • Purchase Order: action_rfq_send overridden to pass product-based attachments (revision TXT + pdf_1_1) into the email composer context for both RFQ and PO emails.
  • New helper: _get_rfq_product_attachments on purchase.order builds the list of temporary attachments (revision note TXT and pdf_1_1) per distinct product on the order lines.
  • Mail Composer: mail.compose.message extended so that when composing an email for a Purchase Order, the product attachments are merged with the template attachments, ensuring they appear in the Compose Email dialog and are sent with the email.

4. USER INSTRUCTIONS

4.1 Setting Up Products

  1. Open the Product form (Product → select or create a product).
  2. Go to the Technical tab.
  3. In the Vendor Drawings/Docs section:
    • Enter the revision information in the new Drawing Revision field (e.g. revision number or notes).
    • Upload the drawing file in PDF 1_1 and set PDF 1_1 filename if desired.
  4. Save the product.

4.2 Sending RFQ or PO by Email

  1. Create or open a Purchase Order (RFQ or confirmed PO) and add order lines with the products that have Drawing Revision and/or PDF 1_1 set.
  2. Click Send by Email (for RFQ) or Send PO by Email (for confirmed PO).
  3. The Compose Email dialog will open with attachments pre-filled:
    • The standard PO/RFQ report (e.g. PO_P01789.pdf).
    • For each product: its revision note file (revision_note_<product>.txt), if Drawing Revision is filled.
    • For each product: its PDF 1_1 file, if uploaded.
  4. Review the recipients and body, then click Send to send the email with all attachments.

5. NOTES FOR CLIENT

  • Attachments created for the email (revision TXT and product PDFs) are temporary and are cleaned up by Odoo's mail composer after use; they do not clutter the database.
  • If the same product appears on multiple lines of the same order, only one revision note and one PDF are attached for that product.
  • This behavior applies to both Send by Email (RFQ) and Send PO by Email (confirmed Purchase Order).
